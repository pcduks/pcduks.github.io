# Pedro Parra — personal site

Live at **https://pcduks.github.io/**. Every push to `main` redeploys through GitHub Actions.

You take seat 32A on a night flight. The window is a live three.js render of the Earth (NASA day and night textures,
clouds, the real sun for the real time, a strobing wingtip) flying the route São Paulo → Kansas City → Berkeley →
Singapore → Tokyo → Bengaluru. The seatback screen is the site: an in-flight entertainment system with a flight map (pick
a leg of the career and the plane flies there), the captain's log, the legs flown, entertainment (projects, with posters
generated by Gemini), the menu (toolkit), duty free (CV and contact) and the safety card (controls). The captain, a voice
synthesised with Gemini TTS, welcomes you and introduces each leg; a Lyria score and a synthesised cabin hum play under
it. The window shade, reading light, tray-table latch and the cards in the seat pocket are all touchable.

There is a static version, the earlier one-page flight log with a dotted globe, for `prefers-reduced-motion`, missing
WebGL, or anyone who adds `?static` to the URL.

Inspired by [Felix Rieseberg's](https://felixrieseberg.com/about-me/) belief that personal sites should still be fun.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static output in dist/
npm run preview    # serve dist/ locally
```

No keys are needed to run or build the site. The optional scripts below use `GEMINI_API_KEY` and `GITHUB_TOKEN`
(see `.env.example`).

## Where everything lives

| Path | What |
|---|---|
| `content/profile.json` | Everything about you: name, tagline, intro, "in flight" list, career legs (with coordinates), toolkit, links, CV path |
| `content/projects.json` | The featured projects (luggage tags): name, description, stack, illustration, status |
| `public/cv/` | Drop your CV PDF here (see below) |
| `public/illustrations/` | Poster art for projects and the static hero, committed so the site never calls Gemini at runtime |
| `src/generated/github.json` | Repository list written by `npm run github`; merged with `projects.json` at build time |
| `content/cabin.json` | The pitch, proof points, principles and the captain's announcements |
| `src/cabin/` | The window seat: `scene/` (cabin geometry, Earth shaders, camera rig), `ife/` (the seatback screen), `audio/` (engine and director) |
| `src/static/`, `src/scene/`, `src/components/` | The static version: dotted globe, split-flap board, boarding passes, luggage tags |
| `public/earth/` | NASA Blue Marble, Black Marble and cloud textures, resized, plus a derived ocean mask |
| `public/audio/` | The score and the captain's announcements (MP3) |
| `scripts/` | `fetch-github.ts`, `import-cv.ts`, `illustrate.ts` |
| `.github/workflows/pages.yml` | GitHub Actions workflow that builds and deploys to GitHub Pages |

## Your CV

1. Save the PDF as `public/cv/Pedro-Parra-CV.pdf` (or change `cv.file` in `content/profile.json`).
2. Rebuild. The "Download CV" buttons appear only when that file exists, so nothing links to a 404.
3. Everything in `public/` is on the open web. Use a version without your phone number.

To refresh the site's text from a new CV:

```bash
GEMINI_API_KEY=... npm run import-cv -- public/cv/Pedro-Parra-CV.pdf
```

That writes `content/profile.draft.json` (it never touches `profile.json`). Diff it, keep the sentences you like, and
copy them across. The script keeps facts and numbers verbatim and only changes the voice.

## Your GitHub repositories

`npm run build` runs `npm run github` first, which asks the GitHub API for your repositories and writes
`src/generated/github.json`. The Builds section then:

- shows the four featured projects from `content/projects.json`, linking to GitHub only when the repo is public;
- lists every other public, non-archived repository under "Also on GitHub".

Without a token only public repositories are visible, which is what the public API returns. In GitHub Actions the
workflow's own token already sees your public repos. To let the build see **private** repositories too (so you can decide
per project whether to feature it), create a fine-grained personal access token with read-only *Metadata* permission and
expose it as `GITHUB_TOKEN` locally or as the `PORTFOLIO_GITHUB_TOKEN` secret in Actions. A private repository is never
listed automatically; it only appears if you add it to `projects.json`, and then without a link.

If the API is unreachable the previous `github.json` is kept, so offline builds still work.

## Illustrations

```bash
GEMINI_API_KEY=... npm run illustrate            # posters for projects that do not have one
GEMINI_API_KEY=... npm run illustrate -- --force # redo all of them
```

Add a `prompt` field to a project in `projects.json` to steer its poster. Convert the PNG to WebP (`cwebp -q 82`) and
point `image` at it.

## Hosting

The site is a static build served by **GitHub Pages** from this repository (`pcduks.github.io`, so it lives at the root
of `https://pcduks.github.io/` with no base path). `.github/workflows/pages.yml` builds and deploys on every push to
`main`; the repository's Pages source is set to *GitHub Actions*.

- **Custom domain:** add it under Settings → Pages → Custom domain. GitHub writes a `CNAME` file; keep it. No code change.
- **Somewhere else:** the output is plain static files in `dist/`. Vercel (framework preset *Vite*), Cloudflare Pages and
  Netlify all work as-is.
- **Project site instead of user site:** if this ever moves to `https://pcduks.github.io/<repo>/`, set the repository
  variable `VITE_BASE` to `/<repo>/`.

## Design notes

- Palette: midnight navy, cream ink, amber, coral. Type: Instrument Serif for display, IBM Plex Mono for the board and
  labels, Inter for reading.
- The globe pauses when the tab is hidden, clamps device pixel ratio to 1.75, and lazy-loads the three.js chunk so the text
  renders first.
- Keyboard in the cabin: `←`/`→` change channel, `↑`/`↓` change leg, `1`–`6` jump to a channel, `Esc` sits back,
  `L` reading light, `W` window shade, `M` mute. In the static version: `↑`/`↓` move between legs, `?` help.
- To regenerate the captain: edit `announcements` in `content/cabin.json`, then run the TTS snippet in
  `scripts/captain.md` (Gemini `gemini-2.5-flash-preview-tts`, voice Charon, filtered with ffmpeg).
- The land dots come from Natural Earth (`world-atlas`, public domain). Flight arcs are cubic Béziers lifted off the sphere
  in proportion to their length.
